# 组件规范

## 组件的共同契约

每个交互组件必须明确适用的状态，而不是只交付一张 default 截图。

| 状态 | 必须表达 | 默认方式 | 常见错误 |
|---|---|---|---|
| default | 是什么、能否操作 | 清楚的文字或图标、必要边界 | 只有鼠标悬停才看得出能点 |
| hover | 指针当前位置 | 轻微背景/文字变化 | 卡片上浮 8px、内容晃动 |
| pressed | 正在按下 | 即时填充变化 | 等网络返回才反馈 |
| focus-visible | 键盘操作位置 | 2px 清晰 outline，2px offset | 只有淡紫光、无可见焦点 |
| selected / current | 已选对象或当前位置 | 中性底 + check/指示条/明确形状 | 只改变色相；与 hover 混淆 |
| disabled | 当前不可操作 | 禁用语义、克制弱化、必要原因说明 | 只降 opacity 但仍能提交 |
| pending | 请求进行中 | 保持尺寸、局部进度、避免重复提交 | 全页遮罩或冒充成功 |
| error | 未成功及如何恢复 | 文字、关联错误、恢复操作 | 只给红边或一闪而过 toast |

**状态优先级：** disabled 不响应操作；pending 避免重复提交；focus 始终可见；selected 在 hover/pressed 中不丢失；错误不取消键盘焦点。多种状态可叠加。

## 按钮

| 变体 | 默认用途 | 视觉 |
|---|---|---|
| Primary | 当前操作组的主要动作 | 反色填充；明确的动词文案 |
| Accent | 登录、引导、品牌流程的主要动作 | `accent.fill` + `accent.onFill`；不是额外的第二主按钮 |
| Secondary | 次要操作 | 透明/表面底 + default 边框 + secondary 字 |
| Ghost | 工具栏、低权重操作 | 无边框，hover 出现浅底，文字仍需可读 |
| Destructive | 删除、撤销授权等危险操作 | danger 文字 + 明确操作名；强确认时可用经验证的危险填充 |

- default 最小高 32px；compact 28px；表单与触控 44px。
- 水平 padding 默认 12px；图标 16px，文字间距 8px；圆角默认 8px。
- 字号桌面 13px / 中文 14px；44px 表单按钮可用 15–16px。
- 主要动作名称具体，如"保存更改""创建项目"，不是所有按钮都叫"确认"或"提交"。
- 普通 hover 不做位移、缩放、投影脉冲；点击反馈不等待网络。
- 加载时保留按钮宽度与可访问名称；必要时 `aria-busy`，并阻止重复提交。
- icon-only 按钮提供可访问名称；视觉图标可以 16px，目标区域不能只有 16px。
- 导航使用链接，执行动作用按钮；不把整个应用全做成可点击的 div。
- 禁用原因在影响任务时应可获得，不能只藏在无法聚焦的 disabled 按钮 tooltip 中。

## 输入、选择与表单

- 默认 min-height 32px，阅读/表单/触控 44px；textarea 按内容增长。
- 背景 `bg.control`；必要边界 `border.control`；文字 primary；placeholder muted。
- 圆角 8px，水平 padding 12px；说明和错误放在字段附近。
- 标签始终可见，默认正常大小写；placeholder 不替代 label。
- 聚焦使用清晰 focus ring；可额外变更边框，但不能只依靠低透明度 glow。
- 错误包含具体问题和修复提示，并关联字段；用户输入不因请求失败清空。
- 必填、格式、长度限制在适当时机说明；错误校验不在每个按键后无差别轰炸。
- 手机输入默认 16px 档，并实测目标浏览器的输入缩放行为；不关闭用户缩放。
- 使用适合内容的输入类型、自动填充、键盘提示；密码支持密码管理器与粘贴。
- 系统选择器已满足任务时优先保留；定制样式不意味着重写所有日期、选择和上传组件。

**复选框、单选与开关：**

- 视觉大小默认 16–20px，但标签和容器扩大实际目标。
- 未选边界和选中 check/圆点都要能辨认；不能用 6% 结构线画一枚近乎消失的复选框。
- 复选框用于多选或独立选择，单选用于互斥项，开关用于立即生效的设置；不因外观相似而互换语义。
- 选中不只靠彩色填充；保留 check、圆点或滑块位置变化。

## 导航、标签页与工具栏

**侧栏：**

- 默认宽 240px，行 min-height 28px；图标 16px，文字 13/14px；组间距 16–24px。
- 普通导航可用 muted，当前项 primary；不要把当前项之外全部降为 disabled。
- 当前项使用中性选中底，并提供可辨认的指示条、形状或其他非纯色相线索；语义上标注当前位置。
- 不默认彩色图标底，不给每行加边框；分组标题不强制 uppercase。
- 折叠导航必须仍可理解；tooltip 是补充，移动端提供完整名称或可展开导航。

**标签页：**

- 切换同一上下文中的面板；导航到独立页面时优先使用链接而非强套 tab 语义。
- 默认高 32px、文字 13/14px；选中使用底形或下划线之一，并保证选中指示可辨认。
- focus 与 selected 分开表达；键盘移动到标签不等于已经执行高成本的数据加载。
- 关闭按钮在 keyboard focus 与触控下必须可发现，不能只有 hover 才能关闭。

**工具栏：**

- 同一类动作在跨页面位置稳定；主次关系由位置、间距和按钮变体表达。
- 默认只显示高频操作，其他进入有名字的更多菜单；不能把所有操作都藏掉。
- 粘性工具栏不得遮住获得焦点的内容；窄屏允许换行或归并。

## 列表、表格与看板

- 默认单行 min-height 36px，compact 28px，触控 44px；正文 13/14px。
- 信息按扫描顺序组织：状态/类型、标识与标题、重要元数据、操作；具体字段以业务为准。
- ID、日期、数字不比标题抢眼；数字列使用稳定宽度与 tabular numbers。
- 数字默认右对齐，文本默认起始对齐；同列内容和表头一致。
- 默认不用斑马纹，不给每行做卡片投影；行分隔线只在真实有助扫描时启用。
- Hover 使用轻微底色；selected 需要明确标记，不能被 hover 样式覆盖。
- 可排序表头要有排序状态与可操作语义；不能只贴一个装饰箭头。
- 次要行操作可在 hover/focus-within 时显示；触控和键盘始终有可达入口。
- 长标题可截断，但必须有详情/展开路径；关键身份、金额、错误不可只剩省略号。
- 数据表保留表头与单元格关系；一般表格不为了样式强行变成复杂 ARIA grid。
- 行内按钮、链接与整行动作不能形成无效嵌套，点击某个按钮不能同时打开整行详情。
- 大列表只在实际需要时分页或虚拟化；一旦虚拟化，保证焦点、读屏顺序和搜索能力不丢失。
- 拖拽排序必须提供非拖拽替代操作；投放位清晰，不能只靠漂浮阴影。
- 看板维持列语义与标题可读；小屏可以逐列浏览或换列表，不把卡片缩成无法点击。

## 卡片、面板与检查器

- 卡片是独立对象容器；面板是工作区域；不要把每个字段都做成卡片。
- 默认 surface + 可选 default 边框 + 12px 圆角；padding 16/24px；普通表面无外阴影。
- 标题默认 16–20px / medium 或 semibold；说明 13–15px / secondary 或 muted。
- 静态面板没有 hover 效果；只有可交互对象才需要可操作反馈。
- 整卡可点击时提供清楚入口，保留内部次级动作的独立语义与事件边界。
- 检查器内字段对齐一致；滚动区域和主区区分清楚，不制造三个互相争夺滚轮的小滚动盒。
- 不在面板中重复嵌套相同边框、相同圆角与相同背景的"套娃卡片"。

## 菜单、下拉与上下文操作

- 容器 raised + strong 边框 + popover 阴影；圆角 12px，padding 4px。
- 菜单项默认 min-height 32px，compact 28px；触控 44px；菜单项圆角 6px。
- 图标可选，不为每个动词配一个图标；快捷键用右侧低权重 kbd。
- 选择型菜单保留 check；危险动作单独分组并有文字说明。
- 默认 160ms 出现、100ms 消失，也可为高频场景取消过渡。
- 支持方向键、Enter、Esc、合理的焦点移动；具体语义匹配菜单或列表选择的真实行为。
- 子菜单需要容错的指针路径；斜向移动不应导致瞬间消失。
- 右键入口必须有等价的可见/键盘/触控入口，不把右键当唯一功能发现方式。
- 浮层避免溢出视口，滚动、缩放和软键盘变化后仍指向正确触发位置。

## 对话框、抽屉与命令菜单

**模态对话框：**

- 默认宽 560px，最大不超过可用视口减 32px；圆角 12px；padding 24px。
- 标题 20/28；正文 15/24；错误保持在对话框内可见。
- 内容过长时内部滚动，关闭入口和关键操作可到达；窄屏可全屏。
- 打开时把焦点送入合理位置；背景不可交互；Tab 不逸出；关闭后焦点返回触发处或合理后续位置。
- Esc 关闭最上层可关闭浮层；有未保存数据时进入确认或保留草稿流程，不能静默丢失。
- 危险确认明确说明对象与后果，默认焦点不诱导不可逆操作。
- 非模态检查器不要误设 `aria-modal=true`，也不要无故困住焦点。
- 2px outline 不能被容器 overflow 裁掉；焦点可见性优先于整洁裁切。

**命令菜单：**

- 是复杂工作型应用的高价值可选能力，不是每个营销站、设置页都必须新增的组件。
- 启用时提供可见的打开入口和 `Cmd/Ctrl+K` 提示，检查宿主快捷键冲突。
- 默认宽 600px，顶部位置可取 15vh，但必须限制最大高度并适应软键盘。
- 输入高 48px，结果行 36px；显示命令名称、必要上下文和已实现的快捷键。
- 搜索、分组、无结果说明必须可理解；模糊搜索与最近使用只在确有价值时增加。
- 键盘焦点/活动结果与已选对象区分；上/下选择，Enter 执行，Esc 退回/关闭。
- 根据真实交互使用 dialog + combobox/listbox 等适当模式，不给静态列表机械添加角色。
- 结果触发异步或危险操作时仍执行原本权限、确认和失败处理，不能因为来自命令面板就绕过。

## 小组件与系统状态

| 组件 | 默认规格 | 必须注意 |
|---|---|---|
| Badge / Tag | 视觉高 20–24px；12px 字；4–6px 或 pill 圆角；中性文字 + 状态点 | 可交互时扩大目标；分类、状态、可移除标签不混为一种语义 |
| 图标 | 16px 主档，20px 独立操作；统一图标家族 | 线性为主，填充可表达状态；不强制禁用所有填充图标 |
| Tooltip | 12–13px；padding 6–8px；8px 圆角；max 280px | Hover 和 focus 都能触发；可关闭、可停留；不放唯一关键说明 |
| Toast | 最大宽 360px；离边 16px；raised；13/14px | 成功提示不抢焦点；错误可持久；动作不能只有几秒可用 |
| Kbd | Mono 11–12px；视觉高 20px；4px 圆角 | 只展示真实可用快捷键；不同平台显示对应键名 |
| Skeleton | 匹配最终布局；低对比静态块，必要时轻脉冲 | 装饰不逐个读出；容器说明忙碌状态；reduce motion 下停止脉冲 |
| Progress | 可测量时显示真实进度，不可测量时明确进行中 | 不编造百分比；耗时任务可考虑取消 |
| Empty | 简短标题 + 原因/说明 + 适当行动 | 区分首次使用、筛选无结果、无权限与加载失败 |
| Error state | 明确失败范围 + 恢复行动 | 保留用户输入；权限错误不假装成空数据 |

图标、插画和 emoji 不是全局法律式禁止项：系统操作图标保持一致；用户内容、头像、真实品牌与有助理解的内容可保留其表达。
