# 间距、密度与布局

## 间距刻度

默认刻度（见 `assets/linear-tokens.css` 的 `--ls-space-*`）：

```text
2 · 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64 · 80 · 96 · 128
```

| 场景 | 默认节奏 |
|---|---|
| 图标与文字 | 6–8px；同类组件统一 |
| 小组件内部 | 4/8/12px |
| 表单项之间 | 16/24px |
| 信息分组 | 16/24/32px |
| 内容面板 padding | 16/24px |
| 页面 gutter | 桌面 24px，窄屏 16px |
| 营销区块 | 桌面 96px，窄屏 48px |

6px 可作为图标间距与圆角的固定配方，不等于需要把所有像素值收进间距表。边框、字形、图片比例与光学对齐无需硬凑 4 的倍数。

## 三档密度

| 模式 | 单行最小高度 | 控件最小高度 | UI 文字 | 适用场景 |
|---|---:|---:|---|---|
| compact | 28px | 28px | 拉丁 13px，中文 14px | 指针/键盘为主的导航、数据工具 |
| default | 36px | 32px | 13–15px | 常规桌面工作界面 |
| comfortable | 44px | 44px | 15–16px | 表单、移动端、触控 |

- 表中是单行参考最小尺寸，不是禁止内容长高的固定 height。
- 缺少合适密度要求时选 default；触控关键操作选 comfortable。
- 一个列表内不能随机混用 28、36、44px；展开行、说明行等有真实内容差异的情况除外。
- 侧栏 compact、主区 default、设置表单 comfortable 可以共存，因为它们职责不同。
- 不能把 28px 的相邻行用重叠透明热区硬扩成 44px；应真正增加行距或换为触控布局。

## 工作型应用外壳

```text
┌─────────────────────┬────────────────────────────────────────────┐
│ 导航 240            │ 位置 / 页面头部 min 44                    │
│ 分组与行对齐        ├────────────────────────────────────────────┤
│                     │ 视图工具栏（仅需要时）                    │
│                     ├──────────────────────────┬─────────────────┤
│                     │ 主工作区                 │ 可选检查器      │
│                     │ 列表 / 表格 / 内容        │ 320             │
│                     │                          │                 │
└─────────────────────┴──────────────────────────┴─────────────────┘
```

- 左侧导航默认 240px，可调整范围建议 224–280px；较长的本地化名称优先折行或扩宽。
- 位置栏说明"在哪里"；视图栏说明"怎么看、如何筛选"。只有职责确实不同才拆成两行。
- 应用头部最小高度 44px；工具多、文字换行或触控场景可增高。
- 检查器默认 320px；剩余主区不够时切换为抽屉，而不是把主内容压成窄缝。
- 列表、表格与看板默认使用工作区宽度；设置与长文可在主区内限宽。
- 同类动作在不同页面保持同一位置；更多菜单的存在不能成为操作随意搬家的理由。
- 浏览器不伪造桌面窗口按钮；桌面容器保留系统拖拽区、窗口按钮和安全区域。

## 营销布局

- 标准内容容器默认 `1200px`；产品大图可使用 `1344px` 宽展示容器。
- 文本区域不因容器宽而无限拉长；Hero 副标题仍受阅读宽度限制。
- 桌面导航默认 72px，窄屏可 56–64px；sticky 时不得遮挡焦点与锚点标题。
- Hero 默认大标题 + 简洁价值说明 + 一组行动 + 真实产品展示，不为套风格强加仪表盘或空洞 3D 图。
- 左对齐适合产品说明；居中适合短句和单一转化。根据内容选一个，不规定"Linear 只能左对齐"。
- 网格按内容组织；不要把所有功能强行塞进同尺寸卡片。
- 背景光效、透视、模糊、视频均为可选，关闭后页面仍然成立。

## 响应式行为

以下为启动断点，不是官方设备分类；主内容放不下时应提前折叠。

| 可用宽度 | 默认行为 |
|---|---|
| ≥1280px | 导航 + 主区；空间足够时展示检查器 |
| 960–1279px | 导航 + 主区；检查器改抽屉 |
| 640–959px | 导航改抽屉；主区单列，次要工具归入更多菜单 |
| <640px | 触控布局、16px gutter、主要操作可直接触达；模态可全屏 |

- 宽度只是信号，还要考虑语言、缩放、输入方式和窗口高度。
- 不在缩放后为了"保持桌面排版"缩小文字。
- 窄屏表格可变为摘要列表 + 详情；需要横向比较的数据可保留局部可滚动表格，不强制损失语义转卡片。
- 表格、时间轴、画布的局部横向滚动不得把普通说明和页面标题一起拖出视口。
- 使用逻辑方向表达起止边、内边距与对齐；RTL 中检查图标、面包屑和浮层方向。
- 移动端检查安全区、软键盘、横屏与短视口，避免底部按钮被遮住。

## 圆角、边框、层级与材质

### 圆角刻度

| Token | 值 | 默认用途 |
|---|---:|---|
| xs | 4px | kbd、小标签、复选框视觉 |
| sm | 6px | 菜单项、小型控件 |
| md | 8px | 按钮、输入、导航行 |
| lg | 12px | 面板、菜单容器、对话框 |
| xl | 16px | 大展示容器、移动 sheet |
| full | 9999px | 头像、胶囊、状态点 |

- 默认按钮 8px；营销 CTA、登录流程和紧凑 pill 控件可用 full。
- [M] Linear 桌面客户端离线容错页的按钮用 `5px`，不是 pill：印证"pill 只用于营销/登录/紧凑场景，系统级功能按钮默认走矩形圆角刻度"这条判断。
- 不把"所有东西一律 12px"当统一；统一的是角色关系。
- 嵌套圆角尽量同心：内圆角可近似 `max(外圆角 − 间隔, 0)`；它是视觉判断，不是所有嵌套元素必须满足的方程。
- 内外同圆角但间隔明显时通常显得鼓胀，应检查。

### 边框与阴影

| 角色 | 表面 | 边框 | 阴影 |
|---|---|---|---|
| 画布 / 正文 | canvas | 默认无 | 无 |
| 面板 / 卡片 | surface | 需要边界时 default | 默认无 |
| 菜单 / Tooltip / Toast | raised | strong | `0 8px 24px rgba(0,0,0,.28)` 深色参考 |
| 模态 | raised | strong | `0 16px 48px rgba(0,0,0,.40)` 深色参考 |
| 必要识别控件 | control | control | 默认无；focus 另加清晰 ring |

- 结构线默认 1 CSS px，不与物理像素混淆。
- 不全局强制 0.5px；不同 DPR、缩放、浏览器下细线会消失或模糊。
- 浮层阴影可以单层或多层，以清晰、低噪和性能为准，不强制某个"神秘复合公式"。
- 不给静态卡片全部加内高光、外发光或投影；没有明确用途时都不要。
- 遮罩是独立背景层，不使用巨大 `100vmax` box-shadow 代替模态语义与焦点管理。

### 材质、图像与光效

- 产品工作面默认不透明；菜单默认不透明，保证不同底图上的可读性。
- 粘性营销导航可用轻度背景模糊，但必须有不透明 fallback，并在实际内容上检查对比度。
- 不把 iOS 自研玻璃材质推广为 Web 设计硬要求。
- 营销页允许一处受控环境光或有真实信息作用的渐变；不是规定"必须发紫光"。
- 不采用"所谓官方原图径向渐变参数"作为身份标记，除非有具体版本和可复核实现证据。
- 指针跟随 spotlight 默认不用；它是特定展示效果，不是工作型 Linear UI 的核心。
- 产品图展示真实信息结构和状态，不以无意义假代码、随机统计和模糊截图填充。
