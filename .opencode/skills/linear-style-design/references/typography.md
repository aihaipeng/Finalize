# 字体与排版

## 字体角色

| 角色 | 默认 | 规则 |
|---|---|---|
| 拉丁 UI 与正文 | Inter Variable | 一个家族即可，不要求额外购买或加载 Display 家族 |
| 展示标题 | 同一 Inter Variable | 可使用 Inter Display，但不是跨架构硬依赖 |
| 中文 / 日文 / 韩文 | 对应语言的高质量系统字体或项目字体 | 必须实测字面、标点、行高；Inter 不覆盖这些正文 |
| 代码、ID、快捷键 | `ui-monospace` 等宽栈 | Berkeley Mono 可选且需要相应授权；不是必需依赖 |
| 品牌化强调标题（如系统级错误/空状态页） | 可选用等宽字体族替代 Inter | [M] Linear 桌面客户端离线容错页标题用 `Berkeley Mono`；属于克制使用的例外场景，不要把正文标题默认换成等宽 |
| 表格数字 | UI 字体 + tabular numbers | 不必为了数字对齐把整张表改为 Mono |

字体栈参考 `assets/linear-tokens.css` 的 `--ls-font-sans` / `--ls-font-mono`。字体名称必须与实际加载的文件 family 对应，不要把 fallback 名称当作已加载证据。

## 字重的统一决策

- 产品基线采用 **400 / 500 / 600**：阅读 / UI medium / 强调。
- 官网拟合模式可用 **400 / 510 / 590**，但必须确实加载支持这些值的可变字体。
- 450 可用于某个字体在 Windows 上偏细的 UI 正文，不再扩散成所有组件的第四种标准。
- 普通 UI 标题不默认使用 700/800；更强层级优先考虑字号、位置、颜色和间距。
- 正文的 `strong`、技术内容与有可读性需要的粗体可以用 700。不能用风格要求取消语义强调。
- 使用常规 `font-weight` 控制字重；不要在祖先上全局固定 `font-variation-settings: "wght" 400`，压过后代字重。
- 非可变字体按可用档位回退到 400/500/600；不以合成 510 作为合格标准。

## 统一字阶

下列 px 是根字号 16px 时的设计参考；Web 实现优先使用对应 rem（见 `assets/linear-tokens.css`）。默认 UI 不因窄屏而缩小正文。

| 角色 | 大小 / 行高 | 字重 | 拉丁字距 | 典型用途 |
|---|---|---:|---|---|
| micro | 11 / 16 | 500 | 0 | 快捷键提示；不用于核心信息 |
| caption | 12 / 18 | 400–500 | 0 | 时间戳、辅助说明 |
| ui | 13 / 20 | 400–500 | 0 | 桌面导航、列表、按钮 |
| ui-cjk | 14 / 21 | 400–500 | 0 | 中文 UI 默认档 |
| body | 15 / 24 | 400 | 0 | 设置说明、产品正文、营销说明 |
| reading | 16 / 26 | 400 | 0 | 文档、较长正文、移动端输入 |
| lead | 18 / 28 | 400 | `-0.01em` | 营销导语；不是密集列表正文 |
| heading-sm | 20 / 28 | 600 | `-0.012em` | 面板、弹窗标题 |
| heading-md | 24 / 32 | 600 | `-0.012em` | 页面标题 |
| heading-lg | 32 / 40 | 600 | `-0.02em` | 大区块标题 |
| display-sm | 48 / 52 | 500 | `-0.022em` | 营销分区标题 |
| display | 64 / 64 | 500 | `-0.022em` | 桌面 Hero |

**中文修正：** 中文正文默认 `letter-spacing: normal`；大标题行高默认至少 1.15，不能把拉丁 64/64 的紧行高无差别照搬。混排需要检查标点、英文 ID 与数字的基线。

## 字距与 OpenType

- 大标题可以轻度负字距；小字号默认不额外收紧，避免中文和低分屏挤压。
- `-0.011em` 是可选拟合值，不是所有正文的必需项。
- `cv01/ss03` 仅在所选字体确实支持且效果符合预期时开启；可以只用于拉丁文本。
- `zero` 默认仅用于技术数据，避免在普通文本里不必要地改变数字观感。
- 不强制把分组标签、表头做成全大写；默认 sentence case，中文正常大小写混排。
- 不用"单词突然变紫、斜体或渐变"作为默认标题强调方式。

## 行长与阅读节奏

- 拉丁长正文默认约 `60–75ch`，最大不宜超过 80 字符左右。
- 中文阅读区默认约 `32–40` 个全角字符宽；不要把 `70ch` 误认成 70 个汉字。
- 长文左对齐，不做两端强制拉伸；标题根据场景左对齐，居中并不违规。
- 标题与说明默认 8–12px；段落间距 12–16px；章节间距 24–40px。
- 标题可平衡换行，但不能靠大量 `<br>` 写死某个桌面宽度的断句。
- 列表摘要可截断，完整内容必须能通过详情、展开或其他可操作方式获得；不要只依赖 hover tooltip。
- 错误、关键条款、表单标签和主要按钮不得因视觉整齐而被不可恢复地截断。
